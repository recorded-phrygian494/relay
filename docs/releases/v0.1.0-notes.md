# relay v0.1.0

First public release. One static Go binary: an OpenAI- and Anthropic-dialect
gateway with cross-dialect translation, routing policies, reliability
machinery, local observability, and an eval harness that gates its own
headline feature. Zero telemetry — not even opt-in pings.

## What works (all fixture-tested; the interesting paths also live-verified)

- **Both dialects inbound, fully**: `/v1/chat/completions` and `/v1/messages`
  (+ `count_tokens`), streaming, tools, vision, cross-translated over a
  canonical IR. Claude Code runs through relay via `ANTHROPIC_BASE_URL`.
- **Providers**: OpenAI, Anthropic, Gemini, Ollama natively; 12
  OpenAI-compatible presets (Groq, Together, Fireworks, DeepSeek, xAI,
  Mistral, Cerebras, Moonshot, OpenRouter, Qwen/DashScope, Zhipu, MiniMax).
- **Routing**: static routes, aliases (fallback / cheapest / fastest /
  weighted), and reliability everywhere: retries with jittered backoff,
  key pools with rate-limit cooldowns, circuit breakers, pre-first-token
  streaming failover.
- **Observability**: SQLite request log with privacy tiers (metadata-only by
  default), Prometheus `/metrics`, one-page `/dashboard`, per-decision
  routing reasons, honest "unpriced" cost states (never a silent $0).
- **Measured overhead**: ~0.18 ms p50 non-streaming, ~0.63 ms added TTFT
  (loopback mock; the <5 ms / <2 ms budgets are hard CI gates).
- **Tools**: `relay compare` (side-by-side output/cost/latency/TTFT),
  `relay eval` (the routing harness, dry-run and live-judged), `relay train`,
  `relay stats`, `relay init` with per-provider key onboarding,
  `/v1/embeddings`, opt-in exact-match cache, `/v1/feedback`.

## What ships off-by-default, and why

**Smart routing.** Our own held-out, live-judged eval (v2 set, judge-scored
real completions — table in the README, raw JSON with a corrections log in
`assets/eval/`): tier 1 failed the cost-at-equal-quality gate; tier 2 passed
within tolerance but remains opt-in for v0.1.0. On that 49-prompt,
700-output-token, single-judge evaluation, the static-cheap baseline received
a higher judged score than the configured frontier baseline — a result
specific to the tested models, prompts, token cap, and judge, not a general
model-quality claim, but reason enough to hold routers to measured evidence.
So the difficulty router ships disabled, enabling it requires an explicit
tier choice, and the README's first instruction is to run `relay eval`
against your own traffic. We consider shipping this honestly to be the
feature.

## Known gaps and untested surfaces

- **OpenAI Responses API**: not supported in v0.1.0. Tracking issue filed at
  launch (binding commitment); target v1.1. Chat Completions is complete.
- **Platform verification**: the darwin/arm64 release-candidate artifact
  passed the full hardware test battery on Apple silicon (11/11 checks —
  evidence: [docs/releases/v0.1.0-rc1-mac-arm64.md](v0.1.0-rc1-mac-arm64.md));
  linux/amd64 was smoke-tested in a clean container and windows/arm64
  natively on the dev machine. darwin/amd64 and linux/arm64 are built by the
  same pipeline but not individually hardware-tested.
- **Install channels**: GitHub Releases and Homebrew
  (`brew install llmrelay/tap/relay`). No npm/PyPI packages exist; a tested
  Dockerfile ships in-repo for self-builds (no published image in v0.1.0).
- Semantic cache, log retention, `translate.strictness`: reserved config
  keys, accepted with a warning, not implemented.
- Gemini 3 multi-turn tool replay is degraded through any cross-dialect
  gateway (thought signatures — documented in `docs/quirks.md`); relay
  detects, warns, and offers routing workarounds.

## Prior art

relay's tier-2 router follows RouteLLM (Ong et al., arXiv:2406.18665) run
locally on your own traffic; graph routers (GraphRouter, arXiv:2410.03834)
are roadmap. Credited in NOTICE and DESIGN.md.
